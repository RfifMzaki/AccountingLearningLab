# Accounting Learning Lab (core)
Run: open this folder in VS Code → install "Live Server" (Ritwick Dey) → right-click `index.html` → Open with Live Server.
No npm or build step. Deploy: push to GitHub → Settings → Pages → deploy from branch (root). All paths are relative.
Data lives in this browser's localStorage (`alab.journal.v1`, `accountingLabLanguage`).
Accounting policy in the sample: straight-line depreciation, 5 years, no salvage; first accounting period; statements are pre-closing.
